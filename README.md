# bboxy450-term

A GPU terminal emulator in Rust built as a cockpit for swarms of coding agents.

Knowledge base and specs live in [`.bboxy/`](.bboxy/README.md). Start at [`.bboxy/vision.md`](.bboxy/vision.md).

Project-owned contributions use the [Respectful Slop License 1.0-Draft](LICENSE).
Slop respectfully. Keep the credit attached: [attribution and reuse](ATTRIBUTION.md).
Upstream terms and earlier MIT/Apache grants remain intact; see [NOTICE](NOTICE).

Build, test, install and package releases through the [Makefile](Makefile): `make help`. `make install` signs the local app; `make smoke` uses a separate unsigned test install.
