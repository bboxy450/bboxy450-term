# bboxy450-plugin

Portable provider manifests, data-source contracts, trust records and named refusals. The host owns execution, authority and storage; this crate owns no process or user interface.

Licensed under MIT OR Apache-2.0. Both licence texts are included.

## Dependency name

The Rust library name remains `bbt_plugin`. Use the existing import name with a versioned package alias:

```toml
bbt-plugin = { package = "bboxy450-plugin", version = "0.1.0" }
```
