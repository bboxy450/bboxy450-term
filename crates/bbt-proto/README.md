# bboxy450-proto

Shared terminal viewport, seat, identity, messaging and GUI wire types. This crate provides schema and serialization; it does not own transports, rendering or application policy.

Licensed under MIT OR Apache-2.0. Both licence texts are included.

## Dependency name

The Rust library name remains `bbt_proto`. Use the existing import name with a versioned package alias:

```toml
bbt-proto = { package = "bboxy450-proto", version = "0.1.0" }
```
