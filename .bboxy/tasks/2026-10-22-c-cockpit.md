**Logic (Rook):** W1.2c ✔ → **W2.4 local messaging** → **S1** `bbt-supervisor` split by process boundary (arch #1) ([[messaging]], [[channel-tree]]): signed envelopes on the local bus, DMs, roles and priority, the channel tree with sinks and symlinks, harness delivery through the W2.3 native paths or PTY fallback; no network transport → **W2.5 MCP server** on a local socket ([[mcp-control-plane]]): seat and screen tools, `message_*`, `ch_*`, task tools (`task_delegate`, report back), `orient`, `graph_read` from the in-memory projection → **W2.5b seat wiring kit**: every seat launched by the app gets, per seat and at launch only (launch flags, env, a per-seat temp config dir; never the user's own config files): (1) our MCP server, (2) the W2.3 hook shim registered for Claude and Codex lifecycle hooks, (3) the `bboxy450` skill, a SKILL.md teaching the agent our tools in order (orient → task_* → message_* → artifact_claim), plus role system prompts from settings. **Identity (next free Executor, after Corvin's identity-custody spec):** **ID1** the full GPG chain per arch #4: GPG root certifies a Keychain-held Ed25519 device key (one prompt per enrollment); the device key certifies seat generation keys in memory; it replaces W2.4's SeatKeys placeholder with envelopes unchanged.
