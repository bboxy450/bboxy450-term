# C — the cockpit: everything local, real; ssh and cloud as dummies (epic)

Owner: Vesper Greywind <ORACLE>. Direction: [[vision]] Cockpit first (operator, 2026-10-22). Done means: open bboxy450-term, launch Claude, Codex and zsh seats with ⌘T, type into them, see live status and subagents in the sidebar, message between seats, delegate a task and get the report back, see provenance and events, all in the lab's look. ssh hosts and cloud providers appear and behave in the UI through a fake provider.

Built on what exists: runtime R1/R2/R4 ✔, logic/store/bus/index W2.2 ✔, byte ring W1.2 ✔, adapters W2.3 ✔, component library W3.2d (L7 finishing at 7.10).

## Tracks, in order, one Executor each

**Terminal (Sable):** R4b GPU → **R3** terminal data path (parser pool, double buffers; consumes the supervisor via W2.2 streams) → **C1 live seats**: the app is a client of the logic process (seat socket, snapshot and deltas), panes render real cells, keyboard input reaches the PTY through the adapter guard, resize, scrollback via W1.2 history pages, close and bring-back.

**UI (Nyx):** 7.9 Settings → 7.10 DocumentModal → **W3.2c** input, focus, ⌘T launcher, signals → fx → **L8 screens** (main window, lifecycle states from `lab/web/lifecycle.html`, perf HUD from `perf.html`) → **L9** screens bound to the live model from C1.

**Logic (Rook):** W1.2c capture latency → **W2.4 local messaging** ([[messaging]], [[channel-tree]]): signed envelopes on the local bus, DMs, roles and priority, the channel tree with sinks and symlinks, harness delivery through the W2.3 native paths or PTY fallback; no network transport → **W2.5 MCP server** on a local socket ([[mcp-control-plane]]): seat and screen tools, `message_*`, `ch_*`, task tools (`task_delegate`, report back), `orient`, `graph_read` from the in-memory projection → **W2.6 provenance and events live**: artifact claim and detection, signed activity log, the events stream exposed to the UI.

**Dummy remote (Rook after W2.6, or whoever is free first):** **D1** a `Provider` trait with `LocalProvider` and a `FakeProvider`. FakeProvider offers ssh hosts and cloud providers, runs "remote" seats as local PTYs labelled remote, simulates connect, latency, disconnect and reconnect states, and is driven by fixtures. The UI shows hosts, providers and remote seats exactly as the real thing will. No quinn, no real ssh.

**Lab (Wren):** reference pages for anything the lab doesn't cover yet: the ssh host list and add-host flow, the cloud provider picker, remote seat states (connecting, latency, offline, reconnecting), the messaging composer and task delegation flow.

**Deferred:** W4.1 quinn transport, real ssh/cloud, cross-instance messaging, global messaging, O1 crate releases.
