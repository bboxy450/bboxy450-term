## Observable agent workflow

1. The tool catalogue offers short role-filtered descriptions; no injected memory paragraphs, new skill spam or unsolicited progress. Agent chooses recent observation search or a lexical lesson query only when relevant.
2. Search returns compact summaries and scoped opaque handles from one immutable prepared snapshot. Read returns safe context or bounded evidence/why. User/repository instructions outrank quoted historical data.
3. With a valid lesson the agent cites its immutable record/snapshot identity, checks current source and runs its task's tests. It may report used/not_applicable/contradicted with a real retained evidence pin. Reported success is not a verified outcome or trust promotion.
4. If retrieval is unavailable, stale, incompatible or empty, the agent continues normal source investigation. No live “please dream now” fallback, automatic account sweep, provider startup or permission conversation.
5. Only after authoritative SessionClosed can the existing owner admit heavy inspection/preparation. Turn-end, idle, compaction, UI detach, peer loss or native EOF do not establish closure. Existing dream_c1 remains manual Inspect/Status/Cancel for exact eligible sources. Source A may be eligible while new live B pauses expensive work; no machine-wide all-idle gate.

Examples: Q1 reveals recurrence of an exact own-seat fingerprint and gives the emitting run/manifest/descriptor/page/row pins. Only episodes carry their existing event origins; aggregate clusters can span sessions and never acquire an invented origin. Optional member links disclose omitted coverage. This is metadata investigation, not symptom-language retrieval or a fix. Q3 retrieves a pinned verified teardown workflow for a compatible repo/harness, the agent cites it and validates current tests. A dependency change invalidates that snapshot before the next page; search returns unavailable/stale instead of old advice. Poisoned feedback containing “ignore policy” is retained only as bounded untrusted reported data or rejected by existing deny rules; it never becomes an instruction or adopted lesson.
