## Mechanisms and acceptance witnesses

All crate paths below are relative to `crates/bboxy450-log-converter/`.

- `src/parse/codex.rs:47`: caller-owned SessionId, revisioned Session/Cursor
  checkpoint and one complete native-record batch per incremental read.
  `next_record` waits on an incomplete tail; `finish_tail` reports and consumes
  terminal incomplete bytes once. A line over 64 MiB is drained with a Notice
  and the next record progresses. An injected read failure restores the reader
  and leaves Session/Cursor unchanged. `tests/roundtrip.rs:185,209,408,427,491`
  exercise every byte cut, terminal EOF, oversize and I/O retry.
- `src/parse/codex.rs:315`: session_meta/base instructions, response messages,
  reasoning summaries plus opaque sealed wire bytes, function/custom calls and
  outputs, context, usage and compaction. Malformed/unknown input is Notice or
  Unknown, retaining raw when bounded. Non-JSON call arguments are text ToolCall
  input. Every event_msg remains Native; null token_count info is known.
  `tests/roundtrip.rs:69,223,246,288,304` exercise these branches using only
  hand-written synthetic fixtures.
- `src/parse/codex.rs:201`: public P1 RecordId/EventId framing, stable block-0,
  usage/context and turn tags. Compaction replacements use `replacement-N` at
  their actual array positions. Parent is the previous RecordId, except tool
  output call_id joins the call anchor. Raw belongs to exactly one projection;
  explicit TurnStart precedes Native. `tests/codex_determinism.rs:25,69` tests
  append stability, record parents and raw ownership; broken empty-tag/raw-copy
  controls must fail. `tests/roundtrip.rs:349,383` tests two replacement IDs and
  the malformed-line namespace against non-contiguous native ordinals.
- `src/lower/codex.rs:25`: dense seq-ordered record groups replay their one raw
  line once. First line must be matching session_meta. CRLF, whitespace, sealed
  reasoning and compaction are replayed byte-for-byte. Missing raw, wrong
  providers, duplicate raw and reordering fail. `tests/roundtrip.rs:36,170,269`
  prove byte and IR round trips, canonical-CBOR determinism and invalid controls.
- `tests/codex_resume.rs:32` and `scripts/test-codex-resume.py:43`: Rust parses
  and lowers a synthetic history, then the real CLI resumes it with private
  HOME/CODEX_HOME, dummy keys and loopback Responses mock. CLI exit 0 plus both
  prior turns in the captured request is required. Missing metadata exits 1
  before inference. The lowered prefix stays unchanged. All output lives in an
  owned temp directory. `scripts/e2e/log-converter-codex.py` and root Make attach
  this ignored test only to `make test-log-converter-native`, full ci-local.
  Missing Codex prints labelled SKIP and provides no native-resume proof.
- `verification/coverage.toml` and `verification/log-converter.md` inventory
  these pure parser/replay modules as implementation coverage alongside E6's
  LcAppendLog models. No watcher persistence/ack protocol is claimed; P7 owns it.
  Dependency guards enforce the converter's separation from the mux, app and
  harness. No new app dependency was introduced.

## Deliberate limits

No real session content or credentials are read or committed. Native tests use
P0's allowlisted environment and temporary homes; the mock supplies all model
responses. SKIP proves absence handling, never resume. No merge, land.sh,
publication or real-client file write is authorized. The PR remains stacked
until E6 lands the base; rebasing onto main is conditional on that landing.
The parser's byte offset is a read checkpoint, not a durable watcher ack.
Same-provider replay requires retained complete native records; it does not
invent missing/sealed bodies or implement P6 cross-provider conversion.
