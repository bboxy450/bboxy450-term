## Removed and reused

Removed C0's single-author restriction and its obsolete rejection expectation. Moved the inline JSONL codec out of the model; its public fixture API remains a re-export, with no duplicate implementation. Append and replay share the existing transition logic. Reused standard file locks, the common operation journal, Tokio's blocking pool, the C0 canvas UI module and the suite GPU renderer; added no renderer, global writer, allocator queue or crate.

## Choices

- Existing `MAX_ELEMENTS=10000`; `MAX_BATCH_OPS=256` bounds one validation/write; process-local `MAX_OPS_PER_MINUTE=2400` over 60 seconds permits diagram batches while limiting a seat's draw rate.
- `PAGE_SIZE=32`; cursor binds swarm, tag and the last activity timestamp/ID key.
- Deterministic 53-bit canvas numbers derived from the create ID, with per-file collision probing, avoid a global number allocator. Slugs are `canvas-<number>`.
- PNGs are 960×640 MCP `image` blocks, also preserved in ctl JSON; no temporary image path or alternate renderer.
- Default drawing authority is creator plus Oracle class; an explicit grant API and showing a canvas remain later steps. Open returns `shown:false`.
